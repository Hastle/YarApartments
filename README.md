# YarApartments

SPA для онлайн-бронирования жилья — региональная сеть апартаментов. Каталог объектов с фильтрацией, карта на основе Яндекс.Карт, страница объекта с бронированием по календарю, личный кабинет с историей броней и избранным.

## Стек

- **React 18**, React Router, React Query — SPA, кэширование запросов к API
- **JWT-аутентификация** (`jose`) — вход/регистрация, приватные маршруты (`PrivateRoute`)
- **Tailwind CSS** + SASS-модули — стилизация
- **@pbe/react-yandex-maps** — карта с метками объектов
- **React Hook Form** — формы бронирования, входа, регистрации
- **Axios** — интеграция с REST API бэкенда
- **Webpack 5** — сборка, dev-сервер с hot reload

## Основные возможности

- Каталог апартаментов с фильтрацией (`Filter`, `MainFilter`)
- Карточка объекта: фото, описание, локация на карте, форма бронирования с выбором дат (`CalendarPicker`)
- Регистрация/вход, JWT-токен, защищённые маршруты
- Личный кабинет: бронирования, избранное, редактирование профиля
- Дашборд для управления объектами (`Dashboard`, `EditApartmentForm`)

## Запуск

```bash
npm install
npm start
npm run build-prod
```

Требуется `.env` с переменными `API_URL`, `API_YANDEX_KEY`, `JWT_KEY` (сервер — отдельный репозиторий).
